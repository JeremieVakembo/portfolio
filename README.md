# Portfolio — Jérémie Vakembo

Portfolio professionnel construit avec :
- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons
- JavaScript léger

## Installation

1. Décompresser le dossier.
2. Ouvrir `index.html` dans VS Code.
3. Utiliser Live Server si disponible.

## Personnalisation

Dans `index.html`, remplacer :
- l'email `tonemail@example.com`
- les liens LinkedIn/GitHub
- les descriptions des projets
- le fichier `assets/cv/cv-jeremie.pdf`
- le bloc photo par une vraie photo dans `assets/img/`

Le design est responsive et fonctionne sur ordinateur, tablette et mobile.
